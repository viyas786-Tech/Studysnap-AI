# StudySnap AI

Paste any notes and instantly get **active-recall flashcards** and a **5-question quiz**, generated by AI. Built for HackDevengers 1.0.

## Problem it solves
Most students re-read notes passively, which is one of the least effective study methods. StudySnap AI converts raw notes into flashcards and a quiz automatically, pushing the student toward active recall — the technique with the strongest research backing for retention — without any manual card-writing.

## Stack
- Next.js (React) frontend + API route backend, single deployable app
- OpenAI `gpt-4o-mini` for generation (use your free OpenAI hackathon credits)
- No database needed — fully stateless, ready to deploy in minutes

## Run locally
```bash
npm install
cp .env.local.example .env.local   # then paste your OpenAI key into .env.local
npm run dev
```
Visit http://localhost:3000

## Deploy to Vercel (use your free Vercel credits)
1. Push this folder to a GitHub repo.
2. Go to vercel.com → New Project → import the repo.
3. In Project Settings → Environment Variables, add:
   - `OPENAI_API_KEY` = your OpenAI key
4. Deploy. Vercel auto-detects Next.js — no extra config needed.
